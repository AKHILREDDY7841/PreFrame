# Core tools status (2026-09-25)

This phase adds a project-scoped, browser-local working surface for Screenplay, Docs & Notes, Shot Lists, Storyboards, Production Schedule, Calendar, Call Sheets, and Locations. Tool data is stored in IndexedDB under the signed-in user and project. The project overview exports and restores these local records separately from the existing cloud project archive. The restore validates the project ID and records before writing them in one transaction. Local writes use record revisions to stop a stale tab from overwriting a newer tab.

The screenplay surface supports nine element labels, Ctrl+1 through Ctrl+9 type shortcuts, ordered elements, selection-anchored comments with orphaning after selected text is removed, and a printable full-script view. Shot and storyboard records support compressed reference-image uploads. Schedule exposes the 15 requested fields in order; Calendar and the Home Upcoming Schedule preview read the same schedule records. A call sheet can take a schedule snapshot and then be published read-only on this device. Free accounts are limited to 50 local shots and 50 local storyboard frames; Premium/Admin local accounts are not subject to that client cap.

The full cloud data path for these tools remains open. Edits do not currently sync across devices or with collaborators. The existing Supabase schema has canonical tables but the tool fields and revision-safe mutations still require integration and backend verification. The project cloud archive does not include local tool records. The Import Script page still validates Preframe archives only and does not ingest Fountain/PDF/Final Draft. The project owner can delete a cloud project through an owner-only Supabase function, but projects with uploaded cloud media are blocked until media cleanup is implemented. Payment and Premium checkout remain separate pending work.

Manual QA: sign in or use the local preview, open a project, visit each tool from the project page, add an item, edit it, refresh, and confirm it remains. Check that Schedule dates appear in Calendar; publish a call sheet and confirm its fields become read-only. In Screenplay, select text, add a comment, insert text before its selection, then delete the selected text and check that its anchor becomes orphaned. Use Print / PDF and check the full screenplay and multilingual text. Export local tool data from the project overview, delete a test item, restore the backup, and confirm the item returns. For a cloud project owner, the Delete project button is beside the title; test only with a disposable project because deletion is permanent.
